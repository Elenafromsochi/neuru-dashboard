# Система вместо хаоса — лендинг программы

Одностраничный сайт: `index.html` (без сборки и зависимостей).

## Что заменить перед запуском
- Фото в папке `img/`: `hero.jpg` (на набережной), `meeting.jpg` (на встрече, на экране Авито), `stage.jpg` (на сцене). Пока фото нет, показывается заглушка.
- Ник Telegram: константа `TELEGRAM_USERNAME` в начале `<script>`.
- Реквизиты исполнителя в подвале (`<footer>`).
